# Demo 范围与验收

> A 阶段人群交互、共享会话与重置现已实现，下面原始骨架范围/旧机器验证记录保留为基线；最新实际范围及未完成运行验收详见 [A交付记录](DeveloperTasks/A_AUDIENCE_DELIVERY.md)。不可将旧机器 iPhone17 点击记录当作本次新增功能已验证。

## 已包含

- 原生 SwiftUI App、共享 Xcode Scheme、iOS 17+ iPhone 竖屏配置。
- 四个 Tab：人群、方案、发送审批、数据。
- 四个独立 NavigationStack，四个首页和四种简单详情占位页；两个人群／方案共用各自详情类型。
- 首页可点击进入详情，系统返回与页面返回按钮，以及底部切换。
- 一份只读本地 Mock：两个人群、两个方案、待审批 A/B 任务、一个历史已发送批次及分析摘要。
- 共享模型、黑白灰样式、常用间距／字体／圆角、卡片、按钮、空状态和格式化。
- README 与六份基础 Docs，多人协作与字段约定；另有完整产品说明副本、开发任务总入口及四份开发提示词。

## 当前不包含

真实接口、登录权限、企业微信调用、店铺后台接入、AI 计算、真实或模拟发送动作、真实统计、数据库和持久化、生产级异常处理、完整 46 页。也不包含比例调整、筛选、历史版本列表、编辑、处理记录、趋势图、资源选择器、完整快照。当前固定示例只支持查看和导航。

App 没有网络层、URLSession、远端图片、WebView 或链接打开行为；没有第三方依赖。App 内没有登录、客户名单或后台服务。Figma 仅作为开发参考，不在 App 运行时访问。
