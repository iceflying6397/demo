## 产品理解与边界

这是原生 iPhone 运营演示 App，闭环是人群 → 方案 → 人工审批 → 模拟执行与效果 → 建议采纳。B 管理内容与规则配置；生日／回访只生成待审批，绝不自动发送。人群关联用 audienceIDs；方案编号稳定，同用途方案合法并存；保存与采纳产生新版本，历史内容保持原样。

遵循零／一个主资源、回访从最近一次购买起算、固定参考日 2026/10/11、日历月计算、显式模拟到期的 Demo 约定。资源、模板、建议和预去重范围均为本地样本，不访问店铺，不调用 AI，不持有客户个人信息。

## 已写入的页面与业务逻辑

- 首页：编号搜索（01／方案 01／首尾空白）、目的与阶段 AND 筛选、计数、清除、空状态；每项仍只有编号、目的、客户。
- 详情：完整话术、ID 解析资源、关联人群及缺失提示、时间／来源、编辑、建议、历史入口。
- 创建／编辑：局部草稿、多行输入、人群多选、模拟模板、字段校验；返回／取消有放弃提示；原创建来源保留；稳定请求 ID 防止重复新增。
- 资源选择：券／商品／抽奖分段、有效期／面额／门槛等信息、独立选择草稿、确定与取消；失效资源可读不可选；可以移除资源保存纯话术。
- 历史：初始 V1 列表和不可变详情，接线后可读后续版本；资源使用当时快照与当时校验日，不重新解析最新对象。
- 建议：当前／建议内容比较、基础版本、参考数据与原因、确认采纳、暂不采纳、真实会话结果页；纯函数阻止过期版本／失效资源／重复采纳。
- 规则：生日与三／六个月回访、启用状态、生成时分、单／双方案、比例与恢复 30/70、草稿校验和只读预览。
- 规则预览：上海参考日、日历月截止日、固定样本范围、版本、资源、预计组人数；生成记录可读冻结配置。纯函数阻止旧预览、重复周期、禁用、空范围和空分组。

未接线时页面显示“保存与任务生成尚未接通”，可校验草稿但不伪造保存、建议处理或新增任务。没有模块级业务 store，没有改写其他 Feature 或 App 根。
