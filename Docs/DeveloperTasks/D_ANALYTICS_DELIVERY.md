## 独立公共增补与 A/B/C 接口

新增 `Shared/Analytics/` 四个文件，是小范围独立公共变更，单独提交供 A 整合；没有修改现有 MockDataStore、已有共享模型、App、主题或工程配置。所有业务样本在 Shared，Feature 中仅有局部查询、图表选择与明确的契约测试状态。

- `AnalyticsDateRange`／`AnalyticsPeriod`：固定上海参考日，包含开始／不包含结束。使用 Gregorian Calendar 的日与日历月计算，不使用设备当前日期或固定90天。
- `AnalyticsValues`：四个可空字段，金额分；计算派生指标。未将旧 MarketingMetrics 的非可空0当未知。
- `AnalyticsPerformance`：唯一键批次ID＋方案ID＋版本，冻结人群版本、方案版本、分配、业务日和来源内容；不查询B的最新内容充当历史。
- `AnalyticsReport`：同一完整查询上下文的摘要、趋势、性能记录、统计状态、去重及来源说明。没有联合摘要的未支持组合为空态。
- `AnalyticsBatchInput`：C提供批次ID、任务ID、人群ID／编号／版本、统计业务日、递增执行revision及每组方案ID／编号／版本／比例／分配人数／累计唯一成功人数／发送内容快照。回调只应由已确认批次产生；重试只更新同批次累计唯一成功范围。未成功客户不计触达。
- `AnalyticsBatchStatistics`：值类型 reducer，无单例／网络／计时器。A在唯一会话中拥有一份。`receive`校验版本、分组与revision并替换快照；成功范围变动后失效旧模拟统计；`load`只存一份匹配结果；`reset`清空新数据。
- `AnalyticsIntegration`：根通过 Environment 注入会话的最新值快照、resetGeneration和返回Bool的加载闭包。首页签名仍 `init(store:)`；缺少注入时读取历史并明确联动未接入。

A 的接线示例（当前仓库无 DemoSession，以下是整合契约，不是现有实现）：

```swift
// DemoSession 持有：var analyticsStatistics = AnalyticsBatchStatistics()
// C 确认和每次模拟执行/重试完成后：
// session.analyticsStatistics.receive(frozenCumulativeInput)
AnalyticsHomeView(store: session.currentStore)
    .environment(\.analyticsIntegration, AnalyticsIntegration(
        statistics: session.analyticsStatistics,
        resetGeneration: session.resetGeneration,
        loadStatistics: { session.analyticsStatistics.load(batchID: $0) }
    ))
// A 统一重置：恢复所有seed；analyticsStatistics.reset()；resetGeneration += 1。
// 根 NavigationStack/Tab 内容用 .id(resetGeneration) 清空所有旧导航与草稿。
```

`currentStore`、`resetGeneration` 是示意接口，由A集中定义，不能假定现在存在。根必须观察唯一会话；每次变化重新传入值快照。旧发送内容由C冻结，D不回写人群、方案或审批。B建议与跨Tab路由由A/B维护；本次只给出对应Tab指引，没有新增建议采纳状态。

联合验证剩余动作：A合入这份公共增补并提供唯一会话；C确认一次人群01 V1／方案01、02 V1／50/50／业务日10/11发送 → 传累计唯一成功回调 → 数据Tab查看统计中 → C重试完成同批次至1000/1000 → D载入模拟统计两次仍一份结果 → A统一重置四模块与导航。任何不匹配配置仍统计中。
